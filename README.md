# תיק העבודות של שחר עזר

אתר סטטי (HTML, CSS ו־JavaScript, בלי שלב בנייה) עם שלושה עמודים:

| קובץ | מה זה |
|---|---|
| `index.html` | פתיח הלומדה, הכותרת והפרויקטים |
| `about.html` | מי אני, מה אני עושה, ניסיון תעסוקתי והשכלה |
| `contact.html` | מסך הסיום הצבעוני עם פרטי יצירת הקשר |

## עדכון תוכן

הפרויקטים, האימייל, הטלפון והקישור ללינקדאין נמצאים ב־`assets/js/config.js`.
שם גם אפשר לבטל את הפתיח (`intro: false`).

## הרצה מקומית

```bash
python3 -m http.server 8000
```

ואז לפתוח את http://localhost:8000.

## פרסום

Settings ← Pages ← Deploy from a branch ← `main`, תיקייה `/ (root)`.
